# НейроЛента — новости про нейросети и искусственный интеллект

Статический сайт-лента новостей про ИИ. Бренд: **НейроЛента**. Обновляется **ежедневно автоматически** через расписание Cline (поиск свежих новостей → запись в `js/data.js` → git push → GitHub Pages).

Живой сайт: https://zahar123421.github.io/ai-news-site/
Репозиторий: https://github.com/Zahar123421/ai-news-site

Темы: базовая **светлая (белая)**, переключатель в шапке (☀️ светлая → 🌙 тёмная → 💻 авто), выбор сохраняется в localStorage.

## Структура

```
ai-news-site/
├── index.html      — главная страница (лента)
├── article.html    — страница статьи (всё внутри сайта, ссылка article.html?id=...)
├── styles.css      — стили (тёмная тема)
├── favicon.svg     — иконка сайта
├── js/data.js      — ⭐ ВСЕ НОВОСТИ лежат здесь (массив items)
├── js/app.js       — рендер ленты, фильтры, поиск, «показать ещё»
├── js/article.js   — рендер страницы статьи и блока «читайте также»
├── server.js       — локальный сервер для проверки
└── README.md       — этот файл
```

**ВАЖНО:** все ссылки ведут ВНУТРИ сайта (`article.html?id=...`). Наружные ссылки на первоисточники в разметку не выводятся — упоминание источника остаётся только текстом в конце статьи. Это сохраняет читателя на сайте (хорошо для рекламы и поведенческих метрик).

## Локальный запуск

```powershell
node server.js
# → http://localhost:8080
```

## Как добавляются новости (правила для авто-обновления)

1. Новости ищутся через веб-поиск за **сегодняшнюю** дату (3–5 штук).
2. Каждая запись добавляется **В НАЧАЛО** массива `items` в `js/data.js` (свежие сверху).
3. Формат записи:
   ```js
   {
     id: "2026-10-06-slug-kratkiy",   // уникальный, дата + короткое название
     date: "2026-10-06",
     title: "Заголовок",
     summary: "2–3 предложения — анонс для ленты, своими словами",
     content: [                        // ОБЯЗАТЕЛЬНО: полная статья, 4–6 абзацев,
       "Абзац 1 — факты, цифры…",      // 150–250 слов, БЕЗ воды, только конкретика,
       "Абзац 2 — контекст…"            // каждый абзац несёт новую информацию
     ],
     category: "Модели",              // Модели | Бизнес | Индустрия | Наука | Общество
     source: "Название источника",
     url: "https://...",              // для архива, наружу не выводится
     media: "img/file.webp",          // опционально: локальное фото/видео-демо
     mediaCaption: "Подпись",         // опционально
     featured: true                   // ТОЛЬКО у одной главной новости; у остальных поля нет
   }
   ```
4. Обновляется `lastUpdated` в начале файла.
5. После добавления новостей сгенерируй обложки: `node tools/generate-covers.js`
   (из заголовка и категории делает `img/cover-<id>.svg` — ничего чужого не тянет).
6. Дубликаты по `id` не добавляются. Старые новости не удаляются (архив растёт).
7. Рекомендуется оставлять не более ~200 записей (удалять самые старые хвостовые).

## Медиа на сайте

- **Обложки** — SVG 1200×630, генерируются локально (`tools/generate-covers.js`), стоят в ленте, в главной новости и в статье.
- **Фото / видео-демо** — локальные файлы в `img/` (пример: `img/promo-kandinsky.webp` — официальная анимация Kandinsky 6.0, лицензия MIT). Подключается полем `media` (+ `mediaCaption`) в записи новости.
- **YouTube** — если у записи есть поле `video` (ID ролика), он встраивается iframe-плеером прямо на страницу статьи — читатель не уходит с сайта.
- Всё лицензируемое скачивается локально в `img/` — сайт не зависит от чужих CDN.

## Публикация (сделать сайтом живым)

### Вариант А — Netlify Drop (самый быстрый, бесплатно)
1. Открой https://app.netlify.com/drop
2. Перетащи папку `ai-news-site` в браузер
3. Получишь ссылку вида `https://случайное-имя.netlify.app` — готово
4. Каждое обновление файлов нужно задеплоить заново (или подключить Git — вариант Б)

### Как ОБНОВИТЬ уже залитый на Netlify сайт
После того как я изменил файлы, на живом сайте пока старая версия. Обновить:
1. **Быстрый способ:** зайди на https://app.netlify.com/drop и снова перетащи папку `ai-news-site` — деплой обновится за ~10 секунд (старый сайт продолжит работать во время загрузки).
2. **Через GitHub (автоматически):** подключи репозиторий в Netlify (Add new site → Import from Git) — тогда каждый push обновляет сайт сам. Инструкция ниже, вариант Б.
3. Переименовать адрес можно в Netlify: Site configuration → Change site name (например, `neirolenta` → `neirolenta.netlify.app`).

### Вариант Б — GitHub Pages (бесплатно + авто-деплой)
1. Создай репозиторий на github.com (например `ai-news-site`)
2. Установи git: `winget install Git.Git`
3. В папке сайта:
   ```powershell
   git init
   git add .
   git commit -m "ИИ Дайджест"
   git remote add origin https://github.com/ТВОЙ_ЛОГИН/ai-news-site.git
   git push -u origin main
   ```
4. На GitHub: Settings → Pages → Source: `main` → Save
5. Сайт появится на `https://ТВОЙ_ЛОГИН.github.io/ai-news-site/`
6. После этого авто-обновления могут просто пушить новые версии.

### Вариант В — свой домен
Домен `*.ru` стоит ~200–1000 ₽/год (reg.ru, namecheap). Привязывается к Netlify/GitHub Pages через DNS.

## Монетизация (когда пойдёт трафик)

- Места под рекламу уже размечены в `index.html` (`.ad-slot`, id `ad-top`) — сюда вставляется код AdSense после одобрения сайта.
- AdSense требует: уникальный домен, работающий контент, страницы «О сайте» и «Политика конфиденциальности».
- Альтернативы: тизерные сети, партнёрки (рефералки на AI-сервисы), премиум-подписка.
